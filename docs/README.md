# Proje belgeleri

Bu klasör Linwas 2.0'ın **tek doğru kaynağıdır** (5 Ekim 2026'dan itibaren).
Daha önce claude.ai'deki "linwas" projesinde tutulan belgelerin kopyasıdır; o kopyalar artık
güncellenmeyebilir.

| Dosya | İçerik |
|---|---|
| [kararlar.md](kararlar.md) | Alınan bütün kararlar: UX, mimari, güvenlik, AI, paketleme, kodlama sırası |
| [yapilacaklar.md](yapilacaklar.md) | Karar/inceleme bekleyenler, bekleyen fikirler, yayın öncesi işler, doğrulanacaklar |
| [tasarim-sistemi.md](tasarim-sistemi.md) | Tasarım sistemi (Microsoft rehberi): düzen, bileşenler, durumlar, hareket, Qt notları |
| [tasarim/tokens.json](tasarim/tokens.json) | Tasarım değerleri (renk, yazı, boşluk, ölçü, hareket) — makine okunur |
| [tasarim/taslaklar/](tasarim/taslaklar/) | v4 taslak kaynakları |
| [dogrulama-raporu.md](dogrulama-raporu.md) | Kodlama öncesi doğrulamalar (PySide6/Python, AI API'leri, dağıtımlar) |

**Kural:** Her kodlama aşamasından önce `yapilacaklar.md` okunur ve bekleyen fikirler hatırlatılır.
Yeni bir karar alındığında aynı değişiklikte `kararlar.md` güncellenir.
